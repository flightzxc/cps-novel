### D-8 · 前台 URL 是否第一天就为 locale 预留

| 项 | 内容 |
| --- | --- |
| **问题** | 立项书 §3.4.3 写 `/novel/{public_page_id}`（**无 locale 段**），同时 §C.2 要求全语种入库、§1.4 把 i18n 前台列为 Out of Scope。三者构成一处缝隙 |
| **为什么必须现在决** | **改 URL 是不可逆的**。一旦被搜索引擎收录、被外链引用，只能靠 308 长期兼容 |
| **本方案推荐** | **第一天就预留**，二选一：① 默认语种无前缀 + 其余带前缀（`/novel/{id}` 与 `/{locale}/novel/{id}`）；② 全部带前缀 |
| **不变的部分** | `public_page_id` 短码体系保留——它解决"改书名不断链"，与 locale 段正交 |
| **成本对比** | 第一天多写一段路径 ≈ 零成本；后期加 locale 段 = 全站 308 + 长期双解析（CPS Page Identity V2 已付过这个账） |
