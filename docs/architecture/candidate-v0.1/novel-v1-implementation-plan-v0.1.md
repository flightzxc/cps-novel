## 0. 与立项书 §十四 的关系

立项书 v0.4 §十四已给出一份 47 项的施工规划（P1 12 / P2 12 / P3 10 / P4 7 / Phase 2 6）。**本文档不是它的替代，是它的重组**——任务简报要求"重新设计 P1–P4，不直接复制已有计划文字"。

重组的动机有两个：一是把"能不能交付"与"依赖什么外部证据"分开（立项书的 P3 里，前半不依赖任何未证合同、后半完全依赖 W9 授权，混在一个阶段里排期会失真）；二是把每阶段的验收口径写成可执行的断言而不是描述。

**立项书的四级 Gate 是权威门禁口径，本文档的阶段映射到它，不另立门禁：**

| 本文档阶段 | 立项书 Gate | 立项书任务 ID |
| --- | --- | --- |
| P1 架构与数据底座 | **Gate A**（本地开工）+ **Gate B**（生产门禁） | P1-01 ~ P1-12 |
| P2 内容与 SEO | **Gate C**（试读展示） | P2-01 ~ P2-12 |
| P3 推广闭环（前半：读已有资源） | **Gate D** 已 PASS 的两项 | P3-01 ~ P3-08 |
| P3 推广闭环（后半：生成能力） | **Gate D** OPEN 项，阻于 **W9** | P3-09、P3-10 |
| P4 收益与归因 | **Gate D** OPEN 项，阻于 **R3** | P4-01 ~ P4-07 |

**当前 Gate 状态（立项书 §二(D)，本方案未改动）**：Gate A = `PASS_FOR_PLANNING`；Gate B = 全部未开始；Gate C = `CONDITIONAL_PASS`（缓存/索引/截断细则待补）；Gate D = 部分 PASS（书目与试读读取、已有推广资源读取），生成合同与收益接口仍 OPEN。

⚠️ 立项书 §十四 开头的红框仍然生效：**"本节只生成任务、依赖、验收与 Gate，不创建任何代码。任何人（包括 Cursor / Codex / Claude Code）不得以本节为依据开始写业务代码，需先由 Owner 单独下达开发指令。"** 本文档同样受此约束。

## 0.1 计划的组织方式

四个阶段，每个阶段结束有一个 **Owner Gate**——不是"汇报进度"，是"没有 Owner 明确放行，下一阶段不开始"。

阶段之间有三条**不可调换的硬前置**：

1. **Worker 原子领取必须在 P2 开始前做对。** P2 的导入、P3 的同步与领链全跑在它上面。做错了后面全部返工。
2. **单一语种真源必须在写入任何多语言数据之前建好。** CPS 为缺这一步付过两次全库归一的代价。
3. **章节表设计必须在 P1 定稿。** 它决定 P2 的模板字段、P3 的同步粒度、P4 的归因维度，且 CPS 无对应物可参照。

工作分配的原则（沿用当前团队的四层分工）：**规划与编排层出方案与验收口径；实现层写码；复核层做独立审查与打包；发布层执行部署**。本文档在每阶段末尾给出可直接交付的任务切分。

## P3 · 推广闭环

> **先把"读已有的"做扎实，再谈"生成新的"。**

### 目标

有推广资源的书能完整跑通"目录 → 页面 → 跳转"；没有的书进入清晰的待办清单。同时，在受控条件下拿到生成能力的真实合同。

### 输入

- P2 全部产出
- Owner 授权的一次受控推广生成探测窗口

### 任务

**一、已有推广资源读取（本阶段主体）**
- 从 `raw_payload` 提取 `kocCode` / `publicUrl` / `homeLink`
- upsert `PromoLink`，`origin=upstream_existing`
- 审计脱敏（掩码 + hostname）
- canonical 投影（第三把钥匙控制，只补空不覆盖）
- 后台"已有推广资源"视图
- **无推广码的书进"待生成"清单**

**二、`/go/:code` 与埋点**
- 跳转 + host 白名单 + 稳定 404
- 埋点批量写 + 独立 flush + 总开关
- IP/UA 盐哈希
- 保留期策略

**三、生成能力合同验证（受控，Owner 陪同）**
- **这是调研动作，不是开发动作**
- 在 Owner 陪同下自然触发一次真实生成，捕获脱敏请求合同
- 确认：Endpoint、Method、Body、幂等规则、写前/写后 readback、是否与短剧 `getcode` 共用
- 产出：接口字段字典条目 + 台账 `P0-X2` 状态更新
- **禁止**：猜测 Path、扫描端点、用生产凭证试探、批量试验

**四、生成能力实现（仅在合同冻结后）**
- 完整领链状态机（四道闸 + 写前意图审计 + 反重复闩 + 有界回读 + 空数据隔离）
- 能力注册表状态从 `registered_disabled` 改 `enabled`
- 后台按钮解禁 + Owner Gate

- ❌ 收益
