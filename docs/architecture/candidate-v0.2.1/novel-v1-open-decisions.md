## 4.5 v0.2 新增待决 → **v0.2.1 全部关闭**

### ~~D-10 · 缺失章节处置策略冻结~~ → **v0.2.1 关闭（`OWNER_DECIDED`）**

冻结后的规则，关键在**先判响应可信度，再谈集合差异**：

| 情形 | 处置 |
| --- | --- |
| 请求失败 / 响应异常 / 异常空列表 | **不改变现有可见状态**（不 stale、不下架、不删除、不更新） |
| 请求成功 + 结构完整 + `chapterList` 非空 | 该列表即**当前权威试读集合** |
| 旧章未再出现在权威列表 | **立即** `stale`：停止展示、退出 sitemap |
| 正文 | **保留，不自动硬删**（硬删仅属人工版权撤回） |
