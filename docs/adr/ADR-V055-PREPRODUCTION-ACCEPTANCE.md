# ADR：v0.5.5 预生产验收证据与收官口径

- 状态：Owner 已确认并授权收官。
- 决策来源：Owner 于 2026-10-01（Asia/Tokyo）在发布聊天提供 Chrome 实测结果，并说明主控 Opus 已核对截图；本 ADR 记录该裁决，不声称 Codex 亲自执行这些交互。
- 记录时间：2026-10-01 00:22:25 +0900；台账时间 2026-09-30 23:22:25 +0800。

## 背景

v0.5.5 已在 haiyue-vps 以 Final `b44b9e2008f66f180fde8b194f5538ebfaf32849` 部署，运行身份和健康核验通过。初轮 HTTP 提取未读到小说 404 品牌页头，首页 absolute 标题、404 本地化标题和分类 sitemap 检查文字与初始提示词字面要求有差异；Codex 浏览器扩展连接不可用。

## Owner 裁决及本次适用边界

1. 采用 Owner 在已登录 Chrome 的实测、主控 Opus 对截图的核对作为本次最终浏览器验收证据，第二阶段全部通过，允许 tag、生成 CHANGELOG、正式开发日志和 Notion 收官。初轮 HTTP 原始结果保留，不能据静态提取结果断言 404 渲染缺少品牌；Owner 已证实页面正常。
2. ko 404 使用本地化 `찾을 수 없음 | PulseNovel`；首页延续已验收的品牌开头 absolute 标题。小说/章节切换到无同书的 English 后，在无前缀英文首页显示原 ko fallbackToast；菜单仅有内容语种与始终保留的 English。博客原开关 false，正常列表属于未启用范围，不能为了验收打开开关。
3. 本版只有 404 是新布局，375px 手机截图由 Owner 在 Chrome 确认并另附；此次不要求补做新的小说布局截图。尚未提供到聊天的图片没有仓库附件路径，收到后再补归档。
4. 分类 sitemap 作为追加记录，在 Owner 所称“明天 04:30 JST 后”仅只读核对。当前客户端日期 2026-10-01，因此安排 2026-10-02 04:35 JST；检查分片内分类页面网址带 /ko/category/，分片文件保持既有 /sitemap/ 路径。不主动刷新、建任务或写库，不将未来结果写成当前已通过。
5. 目标语种已有同一本书时的直达分支目前无真实公开跨语种同书数据，由已有单测覆盖；首次出现数据时补实测，保留明确待办。
6. 收官当时第三阶段模板写库待单独授权和指定 approver；其后 Owner 另行授权、确认 admin，已完成 15 模板标题更新及零变化回读（审计 516113，详见发布记录）；领取批次保持暂停，只由 Owner 恢复。

## 结果

annotated tag v0.5.5 固定在上述 Final，后续治理与追加记录不移动 tag 或改变部署身份。预生产验收按 Owner 裁决通过；公网可见仍以正式域名切换为准。截图与后续 sitemap 记录的实际提供 / 执行状态须据事实追加。

本 ADR 仅决定这次发版证据和收官口径，不修改业务代码、测试门禁、浏览器技能或长期权限规则。
