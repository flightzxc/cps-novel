# ADR：第二段准备暂缓异地恢复演练

状态：accepted；Owner 2026-10-05 交接决定，本会话批准实施的计划再次确认。

## 背景

公网切换手册原要求切换前异地拉取及完整恢复演练均 PASS。本轮只准备证书、旧域名 rehearsal 和容量验证，书籍同步及内容充实完成前不对外开放。

## 决定

- 本段不执行 `restore-offhost-rehearsal.sh`，不创建恢复数据库，不操作 X8。
- 本段备份验收改为确认 VPS 最新逻辑备份 dump、metadata、sha256 三件及其校验，并取得 NAS 最近一次拉取成功的日志或 Owner 确认。NAS 每六小时拉取的配置来自交接记录，不等同本次实测成功。
- 故障处置优先考虑 VPS 本机每日逻辑备份，NAS 异地副本作为最后一道保险；这不是恢复测试通过的声明，也不授权本轮实际恢复数据。
- 仅 nginx 主配置 `worker_connections` 的回退采用独立备份、语法检查和 reload；站点配置仍使用安装器备份。此例外由用户在计划阶段明确确认，因为安装器不管理 events 块。

## 后果与适用范围

异地副本的可恢复性未经实测，存在文件完整但无法完整恢复的剩余风险；三件齐全、散列一致或 `pg_restore --list` 成功都不能代替完整恢复演练。证据必须保留该缺口，不把“暂缓”写成 PASS。

此决定修改本段交付要求，不构成对外开放许可。未来公开切换必须单独确认窗口和届时前置条件，不由本 ADR 自动放行。
