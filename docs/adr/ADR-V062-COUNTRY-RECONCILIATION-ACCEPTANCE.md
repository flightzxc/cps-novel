# ADR：v0.6.2 国家分布对账口径与业务验收

- 状态：Owner 已裁定接受，v0.6.2 业务验收 PASS，原国家逐日对账停点关闭。
- 决策来源：Owner 于 2026-10-17（Asia/Tokyo）在本发布会话明确裁定；记录时间 2026-10-17 22:42:57 JST。
- 适用版本：v0.6.2 PATCH；Final `fbc00167f34cefde6d3f079f8573700ea9e86245`。

## 背景与依据

固定同步批次 `7fd26b71-6831-4d2b-bdb6-faddf702c4cc` 的四天差异均为国家合计大于日报，没有一天偏少：新用户合计 +1，激活逐日累计 +7 人日。10-11 日报激活为 1，国家接口 total 为 2、两个国家各 1。15 份国家快照的明细合计均等于各自 total。原生产解析器离线重放与 34 条国家记录及 9 条日报逐字段一致，没有丢行或重复；17 次既有请求全部 HTTP 200。

Owner 将 10-11 的现象解释为 1 人分列两国各 1，认为与“国家报表按国家分别去重、日报全局去重”一致，据此按“上游接口口径不同”接受。此段记录 Owner 的业务裁定依据，未新增用户级身份实测或上游调用。

## 裁定

1. 国家分布的对账标准改为：**同一天、同一口径的国家明细合计 = 国家接口 total**。本次激活 9 份、新用户 6 份，合计 **15/15 PASS**。
2. 国家报表与日报之间的差异登记为已知上游接口口径差异，不判失败、不再作为 v0.6.2 的发布或业务验收停点。不把国家累计当作与日报同口径的全局去重人数；跨日激活累计记人日。
3. v0.6.2 的业务验收标为 **PASS（附上述口径说明）**。原始跨接口断言失败和只读排查证据保留为历史，不删除、不覆盖，也不篡改为原标准已通过。
4. 本轮只更新治理文档及 Notion，不修改业务代码、生产数据、同步结果、环境配置或既有运行器；不重跑同步、不调用上游、不连接生产主机。tag、Final、tree、镜像和归档工件身份全部保持。
