## 通用约束

- **PostgreSQL only**：不得引入任何 SQLite 方言残留；
- 所有状态类字段（如任务状态、内容状态、凭证状态）必须有 `CHECK` 约束，不允许裸字符串枚举；
- 软删场景使用部分唯一索引排除已软删行（`WHERE deleted_at IS NULL` 类模式）；
- 🔴 **例外**：`public_redirect_code` 的唯一索引**不得**排除软删行——该码全局唯一且**永不复用**，即使原记录被软删除或撤回，其码也不得被回收再分配给其他内容。原因：公开短码一旦被外部链接、被搜索引擎收录、被埋点记录，复用会导致历史流量被错误归因到新内容。
