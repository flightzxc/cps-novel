# Production Release Blockers

本表只记录阻断生产发布的事项。它不授权在开发、验收或金丝雀流程中顺手执行高风险
修复；每项必须按其关闭条件另行审批和验收。

| ID | 状态 | 范围 | 事项 | 本轮约束 | 关闭条件 |
|---|---|---|---|---|---|
| `SEC-CREDENTIAL-KEY-ROTATION-2026-09-01` | `OPEN` | Production release | 海阅本地凭证加密键曾出现在受限工具输出中；值未写入仓库或报告 | Promo Claim / Book B E2E 本轮禁止轮换、禁止直接替换 key file | Owner 单独批准轮换方案；方案必须覆盖现有密文重加密、双版本或原子切换、回滚、凭证解密验证、旧键撤销和发布审计。关闭前不得生产发布 |

## 范围限定备注

### `SEC-CREDENTIAL-KEY-ROTATION-2026-09-01` · 预生产适用性重评估（2026-09-23）

该 blocker **保持 `OPEN`，关闭条件一字未改**。本备注记录一次重评估结论与 Owner 裁决，
不构成豁免。

**取代 2026-09-21 的范围备注。** 那份备注判定"预生产控制面首次启动不落在本 blocker 的
阻断范围内"，其前提中的"不写入任何真实渠道凭据"与"全部渠道写闸保持关闭"自 2026-09-22
起不再成立：预生产已由 Owner 批准录入真实渠道凭据，并开启目录同步与推广领取写闸（写闸
改为登记制，见 `docs/adr/ADR-PREPROD-APPROVED-OPEN-WRITE-GATES.md`）。因此按原备注自身
的约定作废，重新评估。

**2026-09-23 只读审计核实的事实**（未解密任何密文、未打印任何密钥或凭据）：

- **预生产密钥未发现泄露**：预生产的加密密钥与指纹密钥为目标机新生成，经加盐哈希比对，
  与本机全部本地密钥副本均不相同；预生产未导入任何既有密文，未做就地重加密，未替换
  key file。
- **存在跨环境复用的短期 credential**：预生产当前录入的上游令牌，与本地 X8 栈此前录入的
  是同一枚（两边记录的到期时间精确到秒相同）。
- **本地保护该 credential 的旧密钥曾暴露**：本地 X8 栈当前使用的 V1 加密密钥，曾以明文
  出现在本机 AI 工具会话记录中（2026-08-31、2026-09-02），与本 blocker 所述暴露吻合；
  本地从未执行 V1→V2 轮换。
- **未发现当前令牌明文泄露**：预生产数据库（密文列之外的全部表）、预生产服务日志与 nginx
  日志、本地 X8 数据库、本机工作目录与 AI 工具会话记录中，均未发现该令牌明文。
- 因此当前风险是：持有"本地曾暴露的 V1 密钥 + 本地数据库密文"者，**可能**恢复出这枚与
  预生产复用的短期令牌；不是已发现令牌外泄。

**Owner 裁决（2026-09-23）**：

- **不阻断本轮版本的合并与预生产发布**，也不提前额外换签。当前令牌按正常生命周期自然
  到期（`expires_at` = 2026-09-24 05:54:51 UTC）。
- **下一次正常续签必须在预生产独立签发**，新令牌只录入预生产，不再同步到 X8、本地或任何
  其他环境。本轮真正要守住的就是这一条。
- "一套环境一套渠道 credential"的规则随本轮版本写入
  `docs/governance/ENVIRONMENT_PROVISIONING_CHECKLIST.md` §3 与
  `docs/operations/PREPRODUCTION_DEPLOYMENT_RUNBOOK.md`。
- 本地 X8 的 V1 密钥列为**后续安全治理项，不作为本轮发布 blocker**：优先评估直接删除
  本地真实渠道凭据并重新生成本地密钥；确有保留凭据的必要时，再按
  `docs/operations/SEC_CREDENTIAL_KEY_ROTATION_V1_TO_V2_2026-09-02.md` 执行 V1→V2 轮换。

**跨环境 credential 风险的关闭条件**（满足后在本备注补记日期与证据即可关闭该子项）：

1. 当前令牌已过 2026-09-24 05:54:51 UTC；
2. 预生产已按 checklist §3 录入一枚**在预生产独立签发**的新令牌，worker 凭据校验成功；
3. 新令牌的 `expires_at` 与 X8 / 本地任一凭据行都不相同（只比到期时间，不比令牌内容）。

**预生产适用性判断继续成立的前提**（任一条不成立须重新评估）：

- 预生产密钥材料保持目标机独立生成，不导入、不复制任何其他环境的密钥或密文；
- 预生产与生产的真实渠道 credential 不复制到 X8、本地或任何其他环境（checklist §3）；
- 该环境**不对公网开放**：主机 nginx 以 Basic Auth 为主访问控制，并在所有状态码上
  返回 `X-Robots-Tag: noindex, nofollow, noarchive`。

正式生产发布前，该 blocker 仍须按其原有关闭条件单独审批与验收。
